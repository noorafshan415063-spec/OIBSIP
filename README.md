## Projects

### 1. Iris Flower Classification

**Objective:** To classify Iris flowers into three species using machine learning classification algorithms.

**Key Activities:**
- Data loading and preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Training Logistic Regression and K-Nearest Neighbors (KNN)
- Model evaluation using accuracy, confusion matrix, and classification report

**Models Used:**
- Logistic Regression
- K-Nearest Neighbors (KNN)

**Results:** Both models achieved approximately 93.33% accuracy.

[View Project – Iris Flower Classification](./DataScience-Task1-IrisFlowerClassification/)

### 2. Unemployment Analysis with Python

**Objective:** To analyze unemployment trends in India using Python and data visualization techniques.

**Key Activities:**
- Data cleaning and preprocessing
- Monthly unemployment trend analysis
- State-wise unemployment analysis
- Top 10 regions with the highest average unemployment rates
- Correlation analysis
- Rural and urban unemployment comparison
- Pre-COVID and during-COVID unemployment comparison

**Key Findings:**
- Average unemployment during the COVID period was approximately 17.77%.
- Average unemployment before COVID was approximately 9.51%.
- Urban unemployment averaged approximately 13.17%, compared with 10.32% in rural areas.

**Tools Used:** Pandas, NumPy, Matplotlib, and Seaborn.

[View Project – Unemployment Analysis](./DataScience-Task2-UnemploymentAnalysis/)

---

### 3. Car Price Prediction

**Objective:** To predict used car selling prices using machine learning regression algorithms.

**Key Activities:**
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Brand extraction
- One-Hot Encoding
- Correlation analysis
- Training and evaluating regression models
- Feature importance analysis

**Models Used:**
- Linear Regression
- Random Forest Regressor

**Model Performance:**

| Model | MAE | RMSE | R² Score |
|---|---:|---:|---:|
| Linear Regression | 180,194.99 | 385,606.09 | 0.5384 |
| Random Forest | 157,505.36 | 361,448.67 | 0.5944 |

**Result:** Random Forest performed better than Linear Regression across all three evaluation metrics.

[View Project – Car Price Prediction](./DataScience-Task3-CarPricePrediction/)
